[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://ipce.streamlit.app)

Репозиторий **dagan3d/ipce** содержит набор инструментов для анализа данных, получаемых с различного лабораторного оборудования в НИЛ ТНМ.  Основная цель проекта - автоматизация рутинных операций предобработки и визуализации данных, что позволяет исследователям сосредоточиться на интерпретации результатов.

## Ключевые возможности

Приложение предоставляет несколько основных модулей (обработчиков), доступных через главное меню:

*   **IPCE:** Анализ данных зависимости фототока от длины волны падающего света.  Расчет квантовой эффективности (IPCE - Incident Photon-to-Current Efficiency).  Поддерживает несколько форматов файлов данных (.txt, .csv). Позволяет учитывать площадь образца.  Имеет два режима работы - старый и новый (NEW).  Новый режим предназначен для данных, полученных с прибора, измеряющего временную зависимость фототока при различных длинах волн.

*   **Фототоки:** Анализ данных зависимости фототока от времени. Позволяет учитывать площадь освещаемых образцов.

*   **Оптическая ширина запрещённой зоны (OpticEg):**  Обработка данных, полученных на UV-Vis спектрофотометре.  Позволяет строить графики в координатах Тауца ((αhν)^n vs. hν, где n = 2 или 1/2) для определения ширины запрещенной зоны. Поддерживает сглаживание данных и коррекцию скачков, возникающих на спектрах.

* **Оптическое поглощение (OpticAbsorption):** Обработчик предназначен для анализа данных, полученных на UV-vis спектрофотометре. Позволяет проводить коррекцию скачков на спектре, сглаживание, вычитать базовую линию и выполнять фурье-фильтрацию.

*   **SERS:** Анализ спектров комбинационного рассеяния (SERS - Surface-Enhanced Raman Scattering). Включает функции для удаления базовой линии (ALS - Asymmetric Least Squares), поиска пиков и статистического анализа.

*   **Germanium:** Обработчик предназначен для анализа данных, полученных с использованием германиевого детектора.

## Поддерживаемые форматы файлов

В большинстве случаев поддерживаются следующие форматы файлов:

*   `.txt`: Текстовые файлы с разделителями (обычно табуляция или пробелы).
*   `.csv`:  Файлы, разделенные запятыми (или точкой с запятой).
*   `.xls`: Файлы Excel (для OpticEg и OpticAbsorption).
*    `.pts`: Файлы спектров, полученные с прибора, настроенного в НИЛ ТНМ (для OpticEg и OpticAbsorption)

**Важно:**  Формат и структура данных в файлах должны соответствовать определенным требованиям, описанным для каждого модуля (см. ниже).

## Структура файлов данных (для модуля IPCE)

Для модуля **IPCE** (старый режим) ожидается, что входные файлы `.txt` или `.csv` будут иметь следующую структуру:

|  Wavelength, nm   |  Current, A   |
|  ---              | ---           |
|  300              | 1.2E-3        |
|  305              | 0.2E-2        |
|  ...              | ---           |
|  600              | 10.0          |

*   **Первая колонка:** Длины волн (в нанометрах), которыми освещался образец.
*   **Вторая колонка:** Измеренный фототок в амперах.

Для модуля **IPCE (NEW)** требуются файлы с временными зависимостями фототока.  Для корректной работы модуля необходимо получить калибровочный файл. Смотрите описание внутри модуля.

## Установка и запуск

Приложение развернуто с помощью Streamlit Community Cloud.  Для запуска локальной копии:

1.  **Клонирование репозитория:**

    ```bash
    git clone https://github.com/dagan3d/ipce.git
    cd ipce
    ```

2.  **Установка зависимостей:**

    ```bash
    pip install -r requirements.txt
    ```

3.  **Запуск приложения:**

    ```bash
    streamlit run Home.py
    ```

Приложение откроется в веб-браузере.

## Использование (краткое руководство)

1.  **Главное меню (Home.py):**  Выберите интересующий вас модуль (IPCE, Фототоки, и т.д.).

2.  **Загрузка данных:**  Используйте виджет `st.file_uploader` для загрузки одного или нескольких файлов данных.

3.  **Настройка параметров:**  Каждый модуль имеет свои параметры обработки (например, площадь образца для IPCE, параметры сглаживания для OpticEg, точки коррекции для OpticAbsorption).  Эти параметры настраиваются с помощью элементов управления Streamlit (ползунки, флажки, текстовые поля ввода).

4.  **Визуализация:**  После загрузки данных и настройки параметров, приложение автоматически строит графики (используя Plotly).

5.  **Скачивание результатов:**  Результаты обработки (таблицы данных) можно скачать в формате `.csv` с помощью кнопки `st.download_button`.

## Разработка

Приложение разработано с использованием Streamlit, Pandas, NumPy, Plotly, Matplotlib, SciPy и Statsmodels.

Для локальной разработки в VS Code рекомендуется использовать файл `.devcontainer/devcontainer.json`.  Он автоматически настроит среду разработки (Python 3.11, необходимые расширения VS Code, установку зависимостей).
